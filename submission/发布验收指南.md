## 发布文件

解压同目录的 `网站发布包.zip`，把解压后直接包含 `index.html` 的目录部署到静态网站托管平台。发布地址可以是域名根目录，也可以是项目子目录；保留文件夹层级、文件名及大小写。无需安装后端或配置数据库。

发布平台和账号由本人选择并登录，不能以未经确认的账号代替。取得实际网址后，先完成以下手动检查，再运行自动验收。

## 自动验收

本项目已安装的测试环境可使用以下命令。在 `D:\maimai\Vision` 打开 PowerShell，输入已经真实发布的网站目录地址。地址应指向网站目录，保留项目子路径，不带 `index.html`、查询参数或 `#` 路由。

```powershell
$siteUrl = Read-Host '输入已发布的网站目录地址'
node '.\Final\tools\verify-submission.cjs' `
  'C:\Users\24510\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules\playwright' `
  'D:\learn\Python\python.exe' `
  $siteUrl
```

指定地址时，测试直接访问该地址，不启动本地网站替代它。测试需要本机 Edge，以及现有的五个案例解压目录 `Final/tools/qa/submission-audit/extracted`。其他电脑需要相应调整 Node、Playwright 和 Python 的环境路径。

结果保存在 `Final/tools/qa/target-audit/results.json`，截图在同目录。先核对 `target` 确实为要提交的公网地址，再看 `passed` 是否为 `true`、`errors` 是否为空。`mode: supplied-url` 仅表示使用指定地址；如果指定本地地址，不能作为公网发布证据。任何失败都需先处理，不能仅把网址写进材料就认为完成。

自动检查包括五个预载案例、三个页签、每例五张流程图、首个滑块改变显示内容、窄屏横向溢出、c4 曲线重绘、五个提交案例和原始样例的实际导入及刷新恢复、页面异常及站内 HTTP 错误。它不穷举所有交互，不替代人工检查美感、讲解准确性，也不证明其他网络环境下一定能访问。
