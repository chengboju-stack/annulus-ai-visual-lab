## 本地预览与建议体验顺序

在 PowerShell 运行 Final 目录下的 `启动本地预览.ps1`，打开脚本显示的本机地址。按 Ctrl+C 停止服务。本机地址不是公网发布链接。也可直接打开网站文件夹内 `index.html`。

1. 首页检查姓名、学号和固井归属；切换四个固井任务，观察工程素材与输入输出说明联动。
2. 在“先看懂环空”区域切换水泥环、钢套管、井壁，查看对应解释。
3. 进入 c1，背景页切换工程对象、数据证据和方法边界；点开 SVG 图解，放大后用 Esc 关闭。
4. 流程页点选五个步骤或展开全部，检查图解、操作、产出与易错点对应关系。
5. 演示页先选典型工况，保存方案 A，再选另一工况或改变参数，对比当前 B 的指标；可清除对照。A 只保存于本次演示，不作跨设备持久化。
6. 切换“计算依据 / 基线对照”，查看实际方法如何影响结果。其余四例提供同样的探索入口。
7. 案例库按必做、拓展或兼容案例筛选，可按名称、方法、ID 搜索。

## 添加标准案例包

改版门户可直接选择或拖入 ZIP；原有文件和文件夹入口保留。所有读取与解包在浏览器本地完成，不上传服务器。一个 ZIP 只能含一个案例，压缩前后均不超过 6 MB。常见 store / deflate ZIP、中文根目录和数据描述符已验证；破损包和多个案例清单会给出错误。

直接导入：打开“＋ 添加案例” → “选择 ZIP 压缩包” → 选择一个独立案例 ZIP → 查看文件清单与校验 → “校验并添加” → 进入对应场景。存在同场景案例时会出现警告，不是格式错误。刷新后，本机浏览器仍可恢复导入记录。

文件夹兼容导入：先解压案例 ZIP，选择直接包含 `case.json` 的文件夹。老师原始门户若没有 ZIP 功能，仍使用这一方式。单个案例目录如下：

```text
case.json
demo/
  index.html
  demo.css
  demo.js
  scene-illustration.webp
```

清单仍使用原门户的背景、流程、演示字段。交互流程工作台是改版主站的呈现增强；原站读取同一清单时仍能看到五个步骤和五张流程图。演示的工况与 A/B 对比写在独立包内，导入后可运行。

本机导入仅保存在当前浏览器。网站同时从静态文件预载五个原创案例，首次访问即可浏览，不依赖制作者的 localStorage。

## 可视化与交互

五张工程概念素材分别服务五个场景，由 gpt-image-2 API 辅助生成，明确标注非同比例、非现场照片、非计算结果。生成原图位于 `../output/imagegen/final`，完整提示词位于 `../tools/visual-prompts/final`。网站不调用生图服务，不包含接口凭据。

专业背景用剖面、声学示意、数据划分和复核边界解释工程概念；流程每例五步，共 25 张输入输出概念图；演示以 SVG 实算数据图呈现方法输出。首页、背景、流程、演示、目录和导入弹窗采用统一视觉体系。键盘可操作，减少动态偏好下关闭动画。

| 场景 | 实际方法 | 实算依据 / 对照 |
| --- | --- | --- |
| c1 | 最近质心监督分类 | 训练中心、当前特征距离；双特征分类与单声幅阈值的留出准确率 |
| c2 | 回归代理模型与约束搜索 | 六项预测贡献、压力可行域；模型与固定均值的留出 RMSE |
| c3 | 逻辑回归 | 学习权重、截距、sigmoid；模型与训练频率基线的 Brier 分数 |
| c4 | 贪心优化搜索 | 布局覆盖率和数量代价；与同数量均匀布局比较 |
| d2 | 学习正常分布的异常检测 | 60 个正常窗学习均值标准差，z 值与距离评分；另 60 正常窗告警率 |

全部样本为合成教学数据；c4 不含监督训练，d2 不是深度自编码器。置信分、风险分数与异常映射未经现场校准；同源留出成绩不能证明跨井泛化。图表比较如实显示结果，不预设 AI 一定优于简单方法。
