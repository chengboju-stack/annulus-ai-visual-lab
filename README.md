# 环空之间 · 固井智能可视化实验室

程伯驹 · 2406010106 · 可视化导论课程项目。

在线地址：https://chengboju-stack.github.io/annulus-ai-visual-lab/

学号末两位 06 对应第 6 类固井。本项目完成四个固井必做子类，另加一个钻井拓展，共五个原创案例。每例有专业背景、五步案例流程和可运行演示。演示公开实际智能方法、计算依据、简单基线和方案 A/B 对照；教学数据均为合成数据。

网站入口为仓库根目录的 index.html，纯前端，无后端依赖。可在浏览器打开首页，进入案例库或选择添加案例，将 submission/案例压缩包 中任意一个 ZIP 直接导入。原始文件与文件夹导入方式也保留。

submission 目录包含五个独立案例 ZIP、网站发布包、亮点说明 PDF、结课报告 PDF、4 分 43 秒带女声讲解和字幕的 MP4，以及文件校验清单。视频以实际浏览器操作录制，重点说明固井质量评价的 what、why、how 和可视化价值。

所有工程插图用于概念讲解，不是现场照片或计算结果。图表为浏览器内计算的教学结果，未经过现场校准；模型输出不替代工程验收。
